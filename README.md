# Портфолио Даши Кормилицыной

Портфолио на React и Vite: главная страница и кейсы Домклик, Capital.com и Gedocorp. Язык — русский. На экранах уже 768 px используется мобильная версия с бургер-меню и без бокового списка компаний.

## Локальный запуск

Требуется Node.js 22.

```sh
npm ci
npm run dev
```

## Сборка и публикация

```sh
GITHUB_PAGES_BASE=/port-2.0/ npm run build:pages
```

Готовый статический сайт находится в `dist/client`. Сборка рассчитана на адрес `https://dashixa.github.io/port-2.0/`. Для прямого открытия кейсов создаются каталоги `domclick/`, `capital/` и `gedo/` внутри сайта с собственными входными HTML-файлами.

В настройках репозитория **Settings → Pages → Source** следует выбрать **GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует сайт после каждого push в `main`; доступен также ручной запуск. Видимость исходного кода определяется настройками репозитория. Сам сайт Pages доступен публично.

## Медиа и лицензии

Ресурсы сайта находятся в `public/assets`. Видео, восстановленные по оригиналам владельца, не нужно повторно сжимать. Скрипт подготовки медиа — вспомогательный инструмент, для сборки и деплоя не требуется. Исходные внешние папки с контентом остаются у владельца; готовые ресурсы включены в проект.

Звук клика синтезируется локально библиотекой Cuelume. Лицензия MIT и сведения об авторе находятся в `THIRD_PARTY_NOTICES.md` и `public/assets/licenses/cuelume.txt`.

Файл PDF-резюме пока не предоставлен владельцем.
